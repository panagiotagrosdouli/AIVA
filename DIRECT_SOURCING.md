# AIVA jobs: direct sourcing policy

AIVA is its own job-discovery product; it does not claim to own the employer vacancies.

## Public search
- Display verified **direct employer board** listings first.
- The current direct source adapters use publicly published Greenhouse, Lever and Ashby employer boards.
- Preserve links to the original employer application page and source attribution.
- Do not imply all countries, all vacancies or employer partnerships.
- Do not ingest third-party aggregator records into the primary AIVA Platform job listing page.
- Inspect source terms before commercial redistribution; an accessible API is not a blanket license.

## Own listings
The database schema and employer API PR #5 provide the foundation for employer-posted AIVA vacancies, but these are **not live** until an AIVA-dedicated database, secure onboarding, employer verification and moderation are configured.

## Current technical limitations
Career Passport and the legacy homepage may still have separate aggregating feeds. These need migration to the canonical first-party catalog before presenting the entire product as fully direct-sourced.
