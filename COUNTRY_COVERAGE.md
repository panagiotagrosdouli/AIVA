# Country coverage in AIVA
AIVA offers location search for **all countries**, but only returns listings from integrated sources. It does **not** assert vacancy coverage in every country.

- Himalayas covers internationally remote positions subject to employer location restrictions.
- Official employer boards cover the hiring locations where connected employers publish vacancies.
- Arbeitnow focuses mainly on Europe.
- Country filtering searches source-provided location text. It is **not** an eligibility or work authorization check.
- When no listing matches, explain the limited feed coverage rather than claiming the country has no jobs.

Next source onboarding must prioritize explicitly permitted APIs and feeds with country metadata, expiry/freshness, attribution, deduplication, and verified application URLs.
